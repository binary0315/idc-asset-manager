IDC 资产管理｜局域网部署说明

适用场景：一台常开的 Windows 主机运行服务，其他电脑通过浏览器访问，所有人共用同一个数据库。
本仓库只包含源码和说明，不含数据文件；首次启动会自动建库，并在网页上引导创建管理员账号。

主机电脑：
1. 安装 Python 3.10 或更新版本（程序只用标准库，无需 pip install）。
2. 把仓库文件放到长期保存的文件夹（git clone 或下载 ZIP 均可）。
3. 运行 python run_lan.py（等价于把 IDC_HOST 设为 0.0.0.0 后运行 app.py），保持窗口开启。
4. Windows 防火墙弹窗时，只允许「专用/私人网络」。
5. 在「设置 > 网络和 Internet > 当前网络 > 硬件属性」查看主机的 IPv4 地址。

其他电脑：
在同一局域网的浏览器打开 http://主机IPv4地址:8002/，例如 http://192.168.1.20:8002/。
首次使用请先创建管理员账号，之后可在「账号权限」中创建协管员并分配查看/编辑权限。

数据：
所有用户共用主机上的 idc_inventory.sqlite3。该文件首次启动时自动生成，不随仓库分发。
备份时先停止服务，再复制数据库文件；迁移主机时只保留一台服务实例写入，避免数据分叉。
此文件含账号密码哈希与资产数据，不要上传到 GitHub，也不要通过聊天工具传输。

功能提示：
物料台账与入库明细都支持 Excel 预览后导入，预览阶段可手动指定表头所在行和每一列对应的字段。
删除物料会进入回收站（含删除前完整快照），可在「回收站 / 操作日志」中还原或彻底删除。
库存数量只接受正整数，可用库存不允许为负，超额领用/报废会被整笔拦截。

安全：
当前为 HTTP，仅建议用于可信任的内部局域网，不要直接暴露到互联网。
如需公网访问，请置于启用 HTTPS 的反向代理之后，并自行评估认证与访问控制。
